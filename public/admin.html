Pedidos

Registrar pedido manualmente

Para quando a Game Market nao avisar sozinha. O comprador usa a pagina /resgatar com este numero e e-mail.

Log de compras

Cada compra aprovada: dia, hora (horario de Brasilia), jogo, valor e a chave de recuperacao do comprador.

Gerar chaves avulsas

As chaves so aparecem agora. O servidor guarda apenas o codigo de verificacao.

Editar jogo publicado

Altere nome, preco, gratis/pago, capa, descricao e tags. Precisa do token do GitHub.

Desmarcado = gratis (download direto). Marcado = pago (Mercado Pago + chave).

Apagar jogo

Apaga os arquivos do jogo selecionado acima na pasta jogos/<id>/ do cofre. Sem arquivo, o jogo some da loja em ate 5 segundos. Precisa do token do GitHub (Contents: read/write no tss-cofre).

Publicar jogo / nova versao

Envia o .zip para a pasta jogos/<id>/ do cofre privado (cada jogo na sua pasta) e atualiza o catalogo. Precisa do token do GitHub.

Recuperar jogo publicado que nao apareceu

Procura na pasta jogos do cofre versoes que faltam no catalogo (ou estao mais novas) e adiciona com um clique.
