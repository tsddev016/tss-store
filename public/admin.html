★ TSS · Painel de publicação

Publique um jogo (ou uma versão nova). O Hub de quem já tem o jogo mostra “Nova versão detectada” sozinho.

1 · CONEXÃO COM O GITHUB

Crie em GitHub › Settings › Developer settings › Fine-grained tokens, só para este repositório, com Contents: Read and write. Nunca cole o token em lugar nenhum além daqui.

2 · O QUE PUBLICAR

3 · PUBLICAR

Sobe o arquivo em GitHub Releases, calcula o SHA-256 (o Hub confere ao baixar), atualiza o catálogo e o site republica em ~30 s.
